# 📚 Apuntes de Ciberseguridad

Repositorio de apuntes técnicos sobre conceptos de seguridad informática, criptografía, redes y operaciones de seguridad (SOC).

## ⚠️ Cómo visualizar correctamente estos apuntes

Estos archivos están pensados para ser leídos en **Obsidian**.

Aunque puedes verlos directamente en GitHub, **la mejor experiencia** se obtiene abriéndolos con Obsidian, ya que:

- Se renderizan correctamente los enlaces internos (`[[MOC]]`)
- Se aprovechan los *tags*
- Se mantiene la estructura de notas interconectadas
- Se visualizan mejor los bloques de código, tablas y formato avanzado

### ¿Qué es Obsidian?

Obsidian es una aplicación gratuita de toma de notas basada en archivos Markdown.  
Permite crear un sistema de conocimiento personal donde las notas se conectan entre sí mediante enlaces, formando una red de información fácil de navegar (parecido a un segundo cerebro digital).

Es especialmente útil para apuntes técnicos, estudios y documentación.

Puedes descargarlo gratis aquí:  
[https://obsidian.md](https://obsidian.md)

### Recomendación de uso

1. Descarga o clona este repositorio
2. Abre la carpeta completa con **Obsidian**
3. (Opcional) Activa la vista de grafo para ver las conexiones entre las notas
